# Installation and Exploration of Python Data Science Libraries

## Objective
Install and explore commonly used Python libraries for scientific computing, statistical analysis, data manipulation, and data visualization.

## Description
This experiment focuses on setting up a Python-based data science environment and verifying the installation of essential libraries used in data analytics, machine learning, statistical modeling, and visualization.

## Libraries Explored

### Jupyter Notebook
Interactive environment for developing and executing Python notebooks.

### NumPy
Provides support for numerical computations, arrays, and mathematical operations.

### SciPy
Offers scientific and technical computing tools, including optimization and statistical functions.

### Pandas
Used for data manipulation, cleaning, and analysis through DataFrame structures.

### Matplotlib
Provides basic plotting capabilities for creating charts and graphs.

### Seaborn
Builds on Matplotlib to create advanced statistical visualizations.

### Plotly
Enables interactive and web-based visualizations.

### Bokeh
Supports interactive visualizations and dashboard development.

### Statsmodels
Provides statistical tests, regression analysis, and advanced statistical modeling features.

## Software Requirements

- Python 3.13.2
- Jupyter Notebook 7.3.2

## Verification

The installation was verified by importing each library and checking its corresponding version.

## Learning Outcomes

- Successfully configured a Python data science environment.
- Explored the purpose and applications of popular data analysis libraries.
- Verified successful installation of required packages.
- Gained familiarity with tools used for statistical analysis and visualization.

## Result

The required Python libraries were successfully installed and verified. The environment is now ready for performing data analysis, statistical modeling, machine learning, and visualization tasks.
