# Data Visualization Using Normal Curves on UCI Diabetes Dataset

## Aim
To visualize the distribution of key numerical attributes in the UCI Diabetes dataset using normal distribution curves.

## Software Requirements
- Python 3.13.2
- Jupyter Notebook 7.3.2

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy

## Theory
A normal curve (bell curve) represents the probability distribution of a dataset. It helps understand the central tendency and variability of data.

### Key Concepts
- **Mean (μ):** Average value of the dataset.
- **Standard Deviation (σ):** Measures data dispersion around the mean.
- **Kernel Density Estimation (KDE):** A method used to estimate the probability density function of a variable.

The UCI Diabetes Dataset contains various health-related attributes used to study diabetes prediction and diagnosis.

## Procedure
1. Import required libraries.
2. Load the UCI Diabetes dataset.
3. Select numerical attributes such as Glucose and BMI.
4. Create histograms with KDE curves.
5. Overlay normal distribution curves using mean and standard deviation.
6. Analyze the distribution pattern.
