# Diabetes Age Prediction using Linear Regression

## Objective
This experiment aims to predict the age of diabetic patients using Linear Regression. The model is trained on selected health-related features such as Glucose, Blood Pressure, and BMI from the UCI Diabetes and Pima Indians Diabetes datasets.

## Methodology
- Load and preprocess the datasets.
- Select Glucose, BloodPressure, and BMI as input features.
- Use Age as the target variable.
- Split the data into training (80%) and testing (20%) sets.
- Train a Linear Regression model on both datasets.
- Evaluate the model using R² Score, Mean Squared Error (MSE), and Mean Absolute Error (MAE).
