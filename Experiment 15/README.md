# Diabetes Classification using Logistic Regression

## Objective
This experiment aims to classify whether a patient has diabetes or not using a Logistic Regression model. The model is trained and evaluated on both the UCI Diabetes and Pima Indians Diabetes datasets using selected health-related features such as Glucose, Blood Pressure, and BMI.

## Methodology
- Load the UCI Diabetes and Pima Indians Diabetes datasets.
- Select Glucose, BloodPressure, and BMI as input features.
- Use Outcome as the target variable for diabetes classification.
- Split each dataset into 80% training data and 20% testing data.
- Train a Logistic Regression model on both datasets.
- Generate predictions on the test data.
- Evaluate performance using Accuracy, Precision, Recall, and F1-Score.
- Visualize the results using confusion matrix heatmaps.
