# Diabetes Time Series Analysis and Forecasting using ARIMA

## Objective
This experiment focuses on analyzing glucose level data using time series techniques and forecasting future glucose values with the ARIMA (AutoRegressive Integrated Moving Average) model. The analysis helps identify trends, seasonal patterns, and future behavior in glucose measurements.

## Methodology
- Load the diabetes dataset containing glucose level records.
- Visualize the glucose time series to understand data patterns.
- Decompose the series into trend, seasonal, and residual components.
- Apply a 7-point moving average to smooth fluctuations.
- Split the dataset into training and testing sets.
- Train an ARIMA(5,1,0) model on the training data.
- Forecast future glucose levels and compare them with actual values.
- Visualize the forecasting performance using plots.
