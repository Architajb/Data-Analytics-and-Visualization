# NumPy Operations and Array Manipulations

## Objective
Explore and implement fundamental NumPy operations for numerical computing, including array creation, indexing, slicing, arithmetic operations, aggregations, reshaping, and structured arrays.

## Description
This experiment demonstrates the core functionalities of NumPy and its efficient handling of multidimensional data structures. Various array operations are performed to understand data manipulation and mathematical computations.

## Topics Covered

- Array creation (0D, 1D, and 2D arrays)
- Arrays initialized with predefined values
- Indexing and slicing
- Element-wise arithmetic operations
- Scalar operations
- Aggregation functions
- Boolean comparisons and masking
- Fancy indexing
- Array reshaping
- Structured arrays

## Tools and Libraries

- Python 3.13.2
- Jupyter Notebook 7.3.2
- NumPy

## Learning Outcomes

- Understand NumPy array structures.
- Perform array manipulation and transformations.
- Apply mathematical operations on arrays.
- Utilize indexing and filtering techniques efficiently.
- Work with structured data using NumPy.

## Result

Various NumPy operations were successfully performed, demonstrating efficient numerical computation, array manipulation, and data processing techniques.
