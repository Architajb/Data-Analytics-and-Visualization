# Pandas DataFrame Operations for Data Manipulation and Analysis

## Objective
Explore DataFrame operations using Pandas for data inspection, transformation, filtering, grouping, sorting, and exporting.

## Description
This experiment focuses on handling structured datasets using Pandas DataFrames. Various operations are performed to clean, analyze, and manipulate data efficiently.

## Topics Covered

- Loading datasets
- Data inspection and exploration
- Summary statistics
- Handling missing values
- Creating new columns
- Series operations
- Data filtering
- Grouping and aggregation
- Sorting data
- Boolean masking
- Removing duplicates
- Working with subsets of data
- Exporting processed data

## Tools and Libraries

- Python 3.13.2
- Jupyter Notebook 7.3.2
- Pandas

## Learning Outcomes

- Understand DataFrame structures.
- Perform data cleaning and preprocessing.
- Apply filtering and aggregation techniques.
- Generate summary statistics for analysis.
- Export processed datasets for further use.

## Result

The experiment successfully demonstrated essential Pandas operations for data preparation, analysis, transformation, and storage.
