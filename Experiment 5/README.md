# Descriptive Analytics Using the Iris Dataset

## Objective
Perform descriptive analytics on the Iris dataset using Pandas and Seaborn to understand feature distributions and species characteristics.

## Description
This experiment explores statistical summaries and visualizations to identify patterns, trends, and relationships within the Iris dataset.

## Dataset

- Iris Dataset
- 150 flower samples
- Three species:
  - Setosa
  - Versicolor
  - Virginica

## Analysis Performed

### Data Exploration
- Dataset information
- Summary statistics
- Species distribution

### Data Visualization
- Histograms
- Boxplots
- Pairplots

### Feature Analysis
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Tools and Libraries

- Python 3.13.2
- Jupyter Notebook 7.3.2
- Pandas
- Seaborn
- Matplotlib

## Learning Outcomes

- Perform descriptive statistical analysis.
- Visualize feature distributions.
- Compare species characteristics.
- Identify relationships between features.
- Interpret patterns in real-world datasets.

## Result

The experiment successfully demonstrated descriptive analytics on the Iris dataset through statistical summaries and visualizations, providing meaningful insights into feature distributions and species classification.
