# Univariate Statistical Analysis of Diabetes Datasets

## Objective
Perform univariate statistical analysis on the UCI Diabetes Dataset and the Pima Indians Diabetes Dataset.

## Description
This experiment analyzes individual numerical attributes of both datasets using descriptive statistical measures. The goal is to understand the distribution, central tendency, and variability of each feature.

## Statistical Measures Used
- Frequency
- Mean
- Median
- Mode
- Variance
- Standard Deviation
- Skewness
- Kurtosis

## Datasets
- UCI Diabetes Dataset
- Pima Indians Diabetes Dataset

## Tools and Libraries
- Python 3.13.2
- Jupyter Notebook 7.3.2
- NumPy
- Pandas
- SciPy

## Outcome
The analysis provides insights into feature distributions and highlights differences in statistical characteristics between the two diabetes datasets.
