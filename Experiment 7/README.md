# Bivariate Analysis Using Linear and Logistic Regression

## Objective
Perform bivariate analysis on the UCI Diabetes Dataset and the Pima Indians Diabetes Dataset using Linear Regression and Logistic Regression models.

## Description
This experiment investigates relationships between selected variables and evaluates the ability of machine learning models to predict diabetes outcomes.

## Analysis Performed

### Linear Regression
- Independent Variable: Glucose
- Dependent Variable: BMI
- Evaluation Metric: R² Score

### Logistic Regression
- Features:
  - Glucose
  - Blood Pressure
  - BMI
  - Age
- Target:
  - Outcome
- Evaluation Metric: Accuracy Score

## Datasets
- UCI Diabetes Dataset
- Pima Indians Diabetes Dataset

## Tools and Libraries
- Python 3.13.2
- Jupyter Notebook 7.3.2
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Outcome
The experiment evaluates relationships between health indicators and compares predictive performance across the two datasets.
