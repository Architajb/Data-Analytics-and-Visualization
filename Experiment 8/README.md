# Multiple Regression Analysis of Diabetes Datasets

## Objective
Perform multiple regression analysis to predict BMI using multiple health-related features from diabetes datasets.

## Description
This experiment applies Multiple Linear Regression to model the relationship between BMI and selected predictor variables.

## Features Used
- Glucose
- Blood Pressure
- Age

## Target Variable
- BMI

## Evaluation Metric
- R² Score

## Datasets
- UCI Diabetes Dataset
- Pima Indians Diabetes Dataset

## Tools and Libraries
- Python 3.13.2
- Jupyter Notebook 7.3.2
- Pandas
- NumPy
- Scikit-Learn

## Outcome
The model assesses how effectively the selected features explain variations in BMI and compares predictive performance between the datasets.
