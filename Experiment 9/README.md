# Comparative Analysis of UCI and Pima Diabetes Datasets

## Objective
Compare the results obtained from Univariate Analysis, Bivariate Analysis, and Multiple Regression Analysis conducted on two diabetes datasets.

## Description
This experiment summarizes and compares statistical properties and model performances to identify similarities and differences between the datasets.

## Comparison Areas

### Univariate Analysis
- Mean
- Median
- Variance
- Standard Deviation
- Skewness
- Kurtosis

### Bivariate Analysis
- Linear Regression R² Score
- Logistic Regression Accuracy

### Multiple Regression Analysis
- Multiple Regression R² Score

## Datasets
- UCI Diabetes Dataset
- Pima Indians Diabetes Dataset

## Tools and Libraries
- Python 3.13.2
- Jupyter Notebook 7.3.2
- Pandas
- NumPy
- Scikit-Learn

## Outcome
The comparative study highlights variations in data distribution, relationships among variables, and predictive model performance between the two diabetes datasets.
